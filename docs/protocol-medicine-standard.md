# Local protocol medicine standard

Local protocols are used by ED doctors in an emergency. Every medicine entry must be usable without searching elsewhere.

For every medicine, give (from a source actually opened; mark gaps in UNVERIFIED, never invent):
1. The exact level or criterion that selects the dose (for example potassium 3.0-3.4, 2.5-2.9, below 2.5 mmol/L) as its own Branch with an Entry line.
2. Product and strength (for example potassium chloride 40 mmol in 1 L 0.9% sodium chloride, ready-mixed).
3. Preparation: diluent, final volume, concentration, how drawn up (for example 50 units soluble insulin made up to 50 mL 0.9% sodium chloride = 1 unit/mL).
4. Dose, route, line (peripheral or central, pump), rate and maximum rate, duration.
5. Repeat rule and recheck time; what to do if the level is not corrected.
6. Monitoring (ECG, glucose, potassium intervals) and cautions (renal, digoxin, extravasation).
7. Source with exact locator; where guidelines differ, show them in the Guideline comparison.
Derived arithmetic (for example mL/hour from volume and time) is labelled "derived".
Audit rules: "p. N" / "section X" / "Rec. N" locators; one-of steps need 2+ options (single options use Choice "All"); no "or" lists inside one drug cell.
